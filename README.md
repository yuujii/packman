# パックマン (Browser Pacman Game)

ブラウザで動作するクラシックなパックマンゲーム！

## 機能

- **HTML5 Canvasベース**: シンプルで軽量なゲーム実装
- **クラシックなゲームプレイ**: 迷路を移動してドットを集める
- **4つのゴースト**: それぞれ異なる色の敵キャラクター
- **パワーペレット**: 一時的にゴーストを食べられるようになる
- **スコアシステム**: ドット（10点）、パワーペレット（50点）、ゴースト（200点）
- **ライフシステム**: 3ライフでプレイ
- **アニメーション**: パックマンの口の開閉アニメーション
- **📱 スマホ対応**: タッチ操作とレスポンシブデザイン

## 遊び方

1. `index.html` をブラウザで開く
2. 「ゲーム開始」ボタンをクリック
3. パックマンを操作:
   - **PC**: 矢印キー (↑↓←→)
   - **スマホ**: 仮想十字キーまたはスワイプ
4. すべてのドット（餌）を集めてステージクリアを目指す

### スマホでの操作

スマホでは2つの操作方法が利用できます：

1. **仮想十字キー**: 画面に表示される十字ボタンをタップ
2. **スワイプ操作**: ゲーム画面を上下左右にスワイプ

## ゲームルール

- **通常のドット**: 10点
- **パワーペレット（大きな白い玉）**: 50点＋一時的にゴーストを食べられる
- **ゴーストとの接触**:
  - 通常時: ライフが1減る
  - パワーモード時: ゴーストを食べて200点獲得
- **クリア条件**: すべてのドットとパワーペレットを集める
- **ゲームオーバー**: ライフがゼロになる

## ローカルで実行

Webサーバーは不要です。単純に `index.html` をブラウザで開くだけで動作します。

```bash
# または、Pythonの簡易サーバーを使用する場合
python3 -m http.server 8000
# ブラウザで http://localhost:8000 にアクセス
```

## 対応環境

- **デスクトップ**: Chrome, Firefox, Safari, Edge
- **モバイル**: iOS Safari, Android Chrome
- **画面サイズ**: 320px以上（小型スマホ〜大画面PC）
